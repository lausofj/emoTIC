# Reglas de Desarrollo

## Flujo de Trabajo con Git
- **Obligatorio tras cada modificación de código**:
  Cada modificación o conjunto de cambios en el código debe concluir ejecutando:
  ```bash
  git add -A
  git commit -m "<tipo>: <descripción clara del cambio>"
  ```
- No dejar cambios de código sin commitear al finalizar las intervenciones.
- Mantener mensajes de commit descriptivos y profesionales.
